Complete Story v0.7 test build

Requires UE4SS 3.0.1 already installed.

Install
1. Close the game.
2. Extract this archive into the DRAGON BALL Sparking! ZERO game root.
3. Launch normally and wait at least 60 seconds before opening Episode Battle.
4. Select Complete Story and choose New Game.

Rollback
Delete only these two folders while the game is closed:
- SparkingZERO\Binaries\Win64\Mods\CompleteStory
- SparkingZERO\Content\Paks\~mods\CompleteStory

The package does not replace mods.txt and does not edit save files.
