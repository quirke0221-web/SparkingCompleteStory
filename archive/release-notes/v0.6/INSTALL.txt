Complete Story v0.6 (diagnostic gameplay candidate)

Requirements
- DRAGON BALL: Sparking! ZERO Steam build 24953175
- UE4SS 3.0.1 Beta already installed

Install
1. Close the game.
2. Copy the included SparkingZERO folder into the game's root folder.
3. Launch the game and test Episode Battle -> Complete Story once.

The included per-mod enabled.txt is supported by the installed UE4SS build and
does not replace or edit your existing Mods\mods.txt.

Log
- Diagnostic lines begin with [CompleteStory v0.6] in SparkingZERO\Binaries\Win64\UE4SS.log.

Uninstall / rollback
1. Close the game.
2. Delete SparkingZERO\Binaries\Win64\Mods\CompleteStory.
3. Delete SparkingZERO\Content\Paks\~mods\CompleteStory.

This mod does not include or overwrite mods.txt and does not modify save files.
