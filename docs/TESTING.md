# Testing

Before a runtime test, back up saves outside the repository, record installed mods, and isolate unrelated mods if diagnosing a crash. Install only the intended files. Do not alter stock packages, DLC ownership, or multiplayer services.

A bounded test must verify: all twelve stock entries; the Complete Story label/action; the result of one Confirm press; whether a chart, storefront, soft-lock, or crash occurs; and, only if Raditz loads, whether the battle accepts input. Restore saves and isolated mods afterward.

Evidence levels must not be conflated: offline serialization/integrity; container loaded; menu path observed; and battle playable. No version has reached the last level.
