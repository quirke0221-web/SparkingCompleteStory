# FModel - An Unreal Engine Archives Explorer in C#

Source: https://raw.githubusercontent.com/4sval/FModel/master/README.md
Repository: https://github.com/4sval/FModel
Author: 4sval

***

### Description:
FModel is an archive explorer for Unreal Engine games that uses CUE4Parse as its core parsing library, providing robust support for the latest UE4 and UE5 archive formats. It aims to deliver a modern and intuitive user interface, powerful features, and a comprehensive set of tools for exploring, viewing, and extracting game assets.

### Features:
- Support for Unreal Engine 4 and Unreal Engine 5 formats (.pak, .utoc/.ucas IoStore).
- Automatic and manual AES key decryption.
- Mapping file support (.usmap) for un-versioned and obfuscated property serialization.
- Audio player for game audio formats.
- 3D mesh and animation previewer.
- Image viewer with texture channel isolation.
- Virtual package exploration with searchable hierarchy.
