# Design

The intended feature is a separate **Complete Story** option alongside the twelve original Episode Battle campaigns. It is not a duplicate Goku campaign. It should ultimately open its own flow and play the game's existing canonical battles, dialogue, cutscenes, animations, character configurations, events, and charts in chronological order.

The route begins with Goku's canonical Raditz opening and battle, continues through the canonical resolution and the appropriate Piccolo/Gohan material, then advances through Dragon Ball Z and Super from the appropriate viewpoints. Sparking/What-If branches are excluded from the main path.

The current milestone is only `Episode Battle → Complete Story → New Game → Raditz → playable battle`. Continue, Chapter Select, and cross-character progression are not implemented.

Versions v0.1–v0.7 modeled Complete Story as a thirteenth character-campaign record. That proved an extra tile can render, but the native path expects a playable/save identity that the custom key lacks. A product-quality implementation should behave as a menu/orchestration mode. Whether the shipped cooked Blueprint UI can support that packaged-only design remains unproven.

Constraints: preserve all stock campaigns and progress; no DLC dependency; no Goku replacement; no save editing; no redistributed game content; and no claim of success without an observed playable battle.
